# 从这里开始

[返回首页](../README.md) · [学习路线](roadmap.md)

## 第一个小时

前 15 分钟读 [Agent 与 Workflow](chapters/01-foundations.md)，用自己的话解释：谁决定下一步，谁有权执行下一步？接着按首页运行三个 demo。不要急着改代码，先预测输出，再比较实际结果。

用接下来的 30 分钟阅读 [代码导读](code-guide.md)，找到 Planner、工具注册表、检索器和工单状态。最后写下三句话：输入是什么，程序做了什么决定，程序在哪种情况下停止。

没有安装权限时，可以先阅读 `src/agentlab` 和教程，但仍应在后续用自己的环境完成运行与修改。只看运行截图不足以完成实践。

## 先修知识自测

尝试完成以下任务，不必先学框架：

| 任务 | 需要的基础 | 不会时先补什么 |
| --- | --- | --- |
| 读 JSON 并拒绝缺失字段 | Python 类型、异常、函数 | 为一个普通注册表写验证器 |
| 解释 POST 超时后是否重试 | HTTP、网络超时、幂等 | 区分“没收到响应”和“服务端没执行” |
| 用唯一键防止重复创建 | SQL、事务、约束 | 写一次插入和冲突处理 |
| 解释 80/100 与 8/10 的差别 | 概率、采样、统计不确定性 | 计算比例并讨论样本组成 |
| 修改分支并运行测试 | Git、虚拟环境、测试 | 在本地提交一次小改动 |

能完成四项以上，可以直接进入工具项目；两到三项，先用一周补齐薄弱点；不足两项，先练 Python、HTTP 与 SQL，再回来。该划分是学习建议，不是招聘标准。

## 三种读法

**从零学习**：按十周路线完成一章、一项修改、一份记录。遇到术语先查 [术语表](glossary.md)，再读原始资料。

**已经写过 LLM 应用**：从工具项目和工单流程的错误测试开始，重点读评估、安全和生产工程。能调用模型不代表已经处理重试、越权与恢复。

**近期准备面试**：先做一次模拟面试，再针对不会解释的概念回读。至少亲手完成一个项目改动，准备原始评估报告，避免背诵无法落到代码的答案。

## 每次学习留下什么

在自己的笔记中记录：今天的问题、原先的预测、实际结果、失败原因、下一次只改变的一个变量。可复制 [实验模板](templates/experiment.md)。记录不必长，但要让一周后的自己可以复现。

每章练习先独立作答再看答案。对照答案时关注因果链是否完整，而不是文字是否相似。例如“使用重试提高可靠性”缺少条件；应说明错误是否瞬时、操作是否幂等、预算是否允许，以及如何处理执行结果未知。

## 掌握的四个层次

1. **解释**：不看文档，能给出定义、例子和不适用场景。
2. **实现**：独立完成最小代码，并覆盖关键边界。
3. **诊断**：面对失败 trace，能定位数据、决策、执行或评估的问题。
4. **迁移**：换一套数据或业务约束，仍能说明设计为何成立。

“跑通 demo”处于第二层的起点。毕业项目应至少达到第三层，并用一个新任务证明第四层。

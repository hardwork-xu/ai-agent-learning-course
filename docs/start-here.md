# 从这里开始

[返回首页](../README.md) · [学习路线](roadmap.md) · [先修诊断](prerequisites.md) · [动手练习](practice.md)

这条主线面向会写基本程序、尚未系统学习 Agent 的 CS 学生，目标是完成大模型应用开发项目并准备相关实习、校招面试。它包含补课入口，但不能替代一整门编程、算法或计算机系统课程；算法研究与 AI Infra 岗位还需要各自的专项训练。

## 先选自己的起点

| 当前情况 | 从哪里开始 | 先交付什么 |
| --- | --- | --- |
| Python 函数、循环、字典还不熟 | [先修页](prerequisites.md)开头的教程入口 | 独立写一个读取、校验并返回结果的函数 |
| 会编程，没做过后端或 LLM 应用 | [可运行先修诊断](prerequisites.md) | 自己的 JSON、HTTP、SQL 三组答案 |
| 做过后端，第一次学 Agent | [第一章](chapters/01-foundations.md)与[渐进练习](practice.md) | 只读工具、报价工具和持久化迁移题 |
| 已做过 LLM 应用，准备投递 | [毕业项目验收](projects/capstone.md)与[岗位对照](job-readiness.md) | 完整项目证据和一次模拟面试 |

不要把参考实现的通过记录当作自己的作业。仓库自检、学生提交、真实模型实验和真人试学分别回答不同问题。

## 第一次动手

先读第一章，尝试用自己的话解释：谁决定下一步，谁有权执行下一步？然后进入先修诊断，复制起始文件，运行：

```bash
python scripts/grade.py --submission work/my_answers.py --task prerequisites
```

前提是按[先修页](prerequisites.md)创建了自己的答案文件；首次运行应失败，因为函数尚未填写。根据反馈补齐 JSON、重试与事务，再做[第一关只读工具](practice.md)。这一过程先用普通 Python 函数建立输入、校验、执行的概念，不需要模型账号。

随后按首页安装课程包，运行工具 demo，并对照[代码导读](code-guide.md)找到规划器和执行器。写下三句话：输入是什么，程序接受了什么决定，遇到什么条件会停止。默认脚本规划器是确定性教学替身；它的输出不能当作某个模型的能力测量。

没有安装权限时可先阅读，但实践仍需以后在可运行的环境完成。只有截图或参考答案不足以完成课程。

## 用检查点安排进度

[学习路线](roadmap.md)分为基础、独立练习、完整应用和求职准备四段。每段有明确产物和返回条件，按自己的基础调整时间，不承诺固定周数。

应用项目要实际完成中文检索、HTTP 接口、身份权限、持久化审批、失败恢复与评测。仅写系统设计或运行现成 smoke test，还未完成自己的项目验收。真实模型输出质量另做实验，并记录模型、配置、逐题结果和局限。

## 每次学习留下什么

在自己的本地笔记记录问题、原先预测、实际结果、失败原因、看过的提示和下一次只改变的变量。可用[学习记录模板](templates/learning-record.md)或[实验模板](templates/experiment.md)。不保存个人资料、凭据或真实业务数据。

每章题目先独立作答再核对。例如“使用重试提高可靠性”缺少条件；完整解释要说明错误是否暂时、操作是否幂等、预算是否允许，以及执行状态未知时如何核对。

## 掌握的四个层次

1. **解释**：不看文档，给出定义、例子和不适用场景。
2. **实现**：从题目契约写出自己的代码，关键边界可验证。
3. **诊断**：面对失败记录，定位数据、决策、执行或评测的问题。
4. **迁移**：换一套数据或业务约束，仍能实现并说明设计依据。

读过代码、跟做、独立完成都值得记录，但应分别标注。进入求职项目答辩前，至少完成一个独立变式；小组学习可按[试学与评审方案](teaching/pilot.md)记录所需帮助和卡点。没有真人执行过的方案，不能写成已经证明有效的教学结果。

# 术语速查

[返回首页](../README.md)

术语用于定位问题。理解后应能给出例子和反例，而不只是记住中文译名。

| 术语 | 在工程里指什么 | 常见误解 |
| --- | --- | --- |
| Agent | 根据目标和环境反馈动态决定动作的系统 | 接了聊天接口就是 Agent |
| Workflow | 由程序定义步骤与转移规则的流程 | 有条件分支就不算 Workflow |
| Harness | 包裹模型的执行、工具、状态和评估环境 | 能力都来自模型本身 |
| Token | 模型处理文本等输入输出的单位 | 一个汉字永远等于一个 token |
| Context window | 单次调用可处理的上下文容量 | 能放进去就能可靠利用 |
| Embedding | 将对象映射为用于相似度等任务的向量 | 相似度高等于事实正确 |
| Attention | 按相关性聚合表示的机制 | 权重就是可靠的因果解释 |
| KV cache | 自回归推理中复用注意力键和值 | 等于跨会话长期记忆 |
| Tool calling | 模型提出结构化工具调用请求 | 模型拥有执行和授权权力 |
| Schema | 数据结构和部分约束的契约 | 格式合法就符合业务语义 |
| RAG | 检索外部证据后辅助生成 | 等于向量数据库 |
| Chunk | 文档切分后的索引单位 | 越小越精确，越大越完整 |
| Recall@k | 前 k 个结果覆盖相关项的比例 | 命中任意一项就是完整召回 |
| Hit@k | 前 k 个结果是否至少命中一项 | 与多相关文档的 Recall@k 完全相同 |
| Reranker | 对候选资料进一步排序的模型或方法 | 能找回初筛完全漏掉的资料 |
| Grounding | 把回答绑定到可检查的证据 | 加上引用编号就完成验证 |
| Abstention | 证据不足时拒绝给出未经支持的结论 | 所有拒答都提高系统质量 |
| Context engineering | 组织一次调用实际看到的信息 | 不断增加提示词长度 |
| Memory | 跨步骤或会话保留的信息机制 | 所有对话都应该永久保存 |
| Checkpoint | 用于恢复的状态快照 | 远端副作用也会自动回滚 |
| Idempotency | 同一操作重复提交具有约定的一致业务效果 | 重复执行代码一定安全 |
| Retry | 在条件允许时重新尝试请求 | 超时一定意味着尚未执行 |
| Backoff | 失败后按策略延后重试 | 只要等待就不会加剧拥塞 |
| Backpressure | 在下游饱和时限制上游输入 | 无限制排队也能保证可用性 |
| ACL | 对主体访问对象或动作的权限约束 | 放进提示词就是权限控制 |
| Tenant | 需要隔离数据和权限的客户域 | 可以由模型随意填写 |
| Prompt injection | 不可信内容试图影响指令或行为 | 只来自用户直接输入 |
| Approval | 对具体动作及上下文的授权记录 | 一次同意可覆盖任意后续动作 |
| Trace | 一次执行的事件与关联记录 | 必须记录全部秘密和原始推理 |
| SLO | 某段时间内服务应达到的可测量目标 | 单次 demo 达标就是稳定达标 |
| Baseline | 用于比较的明确参考方案 | 应选一个明显很差的方案 |
| Ablation | 移除或替换组成部分以考察其作用 | 同时改多个变量也能归因 |
| Data leakage | 评估信息不恰当地进入开发或训练 | 只有复制原题才算泄漏 |
| LLM-as-judge | 使用模型按规则评估输出 | 模型打分就是无偏真值 |
| Fine-tuning | 用训练数据更新模型参数 | 增加上下文示例也是微调 |
| SFT | 用监督样本训练输出行为 | 只需成功轨迹就足够可靠 |
| RL | 根据奖励优化策略的学习过程 | 文字反思天然包含参数训练 |
| MCP | 工具与上下文连接的协议体系 | 接入协议即可消除安全风险 |
| A2A | Agent 间互操作的协议体系 | 普通多角色 prompt 自动兼容 |

需要完整推导时返回对应 [章节](../README.md)；协议版本见 [协议与框架](ecosystem.md)。

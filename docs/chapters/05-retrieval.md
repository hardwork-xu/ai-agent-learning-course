# 05｜RAG：找到证据，还要证明答案用对了证据

[上一章](04-tool-use.md) · [首页](../../README.md) · [下一章](06-memory-and-context.md)

**本章目标：**理解检索流水线，能区分检索失败、生成失败和权限失败。先修要求：向量相似度、基本数据库查询。

## 从文档到答案的完整链路

一个常见 RAG 流程是：

```text
资料授权与解析 → 按结构切块 → 建索引与版本记录
用户问题 → 身份与范围校验 → 召回 → 重排 → 证据选择
→ 带证据生成 → 引用与业务校验 → 答案或弃答
```

[RAG 论文](https://arxiv.org/abs/2005.11401)研究了参数化生成模型与检索知识结合的方法。[DPR](https://arxiv.org/abs/2004.04906)展示了用稠密表示进行开放域段落检索的路线。工程系统不必一次实现所有复杂组件：小语料的关键词检索，也是应该保留的可解释基线。

切块不是机械地每 500 字截断。条款标题、适用对象、否定条件、表格列名若被切开，召回的内容可能无法独立解释。可以用章节为主、长度为辅，保留父级标题与相邻块引用。重叠提高上下文连续性，也增加存储、重复召回和计分偏差。

## 关键词与向量检索如何互补

关键词方法常适合型号、错误码和专有名称；向量方法常适合改写和语义相近的问题。余弦相似度为：

$$
\mathrm{sim}(q,d)=\frac{q\cdot d}{\|q\|\|d\|}
$$

它衡量表示空间中的方向接近程度，并不验证文档支持某个结论。“允许外借”和“不允许外借”可能拥有大量相同词语，语义向量也可能接近。重排模型可以联合查看问题与候选段落，但仍须测漏召回、时延和失效场景。

先确保正确证据进入候选集合，再优化排名。若正确规则没有入库，换 reranker 无法找回它；如果召回的是去年规则，提高相似度也无法解决版本问题。

## 每个结论需要哪一段依据

证据记录至少包含：

```json
{
  "document_id": "equipment-policy",
  "revision": "v3",
  "chunk_id": "section-4",
  "source_locator": "第 4 节，第 2 段",
  "valid_from": "2026-01-01",
  "text": "教学借用需要课程负责人确认。"
}
```

这是合成示例。文档 ID 解决身份，版本解决变更，位置解决可复查性，生效时间解决时态。检索时间与生效时间不能混为一谈：今天检索到的页面，可能描述上学期规定。

引用核验需要两个问题：引用确实存在吗？引用真的支持当前句子吗？例如“教学借用需要确认”不能支持“所有人都不能自行预约”。回答最好按结论逐一关联片段；找不到依据时缩小结论或明确缺口。

## ACL 必须在资料暴露前生效

访问控制列表（ACL）应限制检索候选、片段读取与答案缓存。把无权访问的片段交给模型，再提示“不要透露”，已经越过了边界。

用户身份和租户来自认证层，不能让模型在工具参数中自行声明。数据库、向量库或服务层需要强制过滤，后端取原文时再次核验。缓存键至少考虑权限范围与文档版本，避免上一位用户的答案复用给下一位用户。

[PostgreSQL RLS 文档](https://www.postgresql.org/docs/current/ddl-rowsecurity.html)提供了数据库行级策略的实现参考，并明确指出超级用户、具有绕过权限的角色及通常的表所有者可能绕过策略。开发环境用管理员账号测通查询，不能证明生产账号隔离有效。

## 用分层指标定位故障

对一个问题，设标注的必要证据集合为 $G$，前 $k$ 个召回结果为 $R_k$：

$$
\mathrm{Recall@k}=\frac{|G\cap R_k|}{|G|},\qquad
\mathrm{Precision@k}=\frac{|G\cap R_k|}{|R_k|}
$$

需预先规定评价单位是文档还是片段，并去重。若标注并不穷尽所有有效证据，Precision 会被低估；没有可用证据的问题应单独评价弃答，不能把 $|G|=0$ 直接带入公式。

端到端还要检查结论正确、引用支持、过期信息和越权暴露。检索 Recall 高只能说明候选包含证据，不能证明生成器用了它。

## 动手练习与答案

题目需要“课程负责人批准”和“库存充足”两条证据。前 3 条召回中，只有批准规则相关，其余是同一旧公告的两个完全重复副本。约定以去重后的证据为单位计算指标。计算指标并给出下一步。

**参考答案：**去重后有 2 条证据，其中 1 条相关，因此这批候选的 Recall = 1/2、Precision = 1/2；若不去重而按三个返回条目计数，Precision 会是 1/3，那属于另一种口径，不能混用。更关键的是：缺少库存证据，不能宣称可借。库存通常应查询实时工具，不能从历史公告推断。

**自评标准：**指标单位与分母写清；识别重复候选；区分静态规则与动态库存；答案不超出证据。

## 面试追问

**“有引用就能解决幻觉吗？”** 不能。可能引用虚构、引用不支持结论、规则已过期或忽略关键例外。分别用来源校验、支持性检查、版本控制和边界样例评价。

# 论文阅读与可复现实验

[返回首页](../README.md) · [研究前沿](chapters/12-research-frontier.md) · [实验模板](templates/experiment.md)

研究训练的核心是把一个直觉变成可以被反例推翻的假设。论文中的有效方法，不能脱离数据、环境、预算与评估方式直接搬到另一个任务。

## 四篇论文，四种阅读问题

| 论文 | 重点读什么 | 不应直接推出什么 |
| --- | --- | --- |
| [ReAct](https://arxiv.org/abs/2210.03629) | 推理与环境交互如何交替，反馈如何改变下一步 | 多写推理文字一定提高所有任务质量 |
| [Reflexion](https://arxiv.org/abs/2303.11366) | 反馈怎样写进文本记忆并影响后续尝试 | 文本反思等于通过梯度更新模型参数 |
| [SWE-bench](https://arxiv.org/abs/2310.06770) | 真实仓库问题、补丁与测试组成怎样的评估环境 | 通过测试就证明满足全部真实用户需求 |
| [τ-bench](https://arxiv.org/abs/2406.12045) | 工具、用户交互与业务规则怎样共同决定成功 | 某次成功就说明重复运行同样可靠 |

每篇先记下任务、输入输出、评估方式和关键假设，再读方法细节。原论文的历史结果属于原实验配置，不能当作当前模型排名。

## 一张论文卡片

- **问题**：现有方法在哪类输入上失效？
- **干预**：方法究竟改了模型、提示、检索、预算还是执行环境？
- **证据**：哪个实验直接支持核心论点？
- **混杂**：是否同时增加了调用次数、上下文和工具能力？
- **边界**：数据是否可能出现在训练中，环境是否足够真实？
- **迁移**：在自己的任务中哪条假设可能不成立？

如果只能复述架构图，无法回答这些问题，说明还没有读到实验设计这一层。

## 实验 A：检索前的任务改写是否值得

**假设**：在包含同义表达的查询上，查询改写提高证据命中率，但可能增加成本并损害精确编号查询。

构造至少四个查询桶：原词命中、同义改写、明确编号、无答案。先用仓库检索器建立离线基线，再单独增加人工预定义改写或真实模型改写。两者分开报告；人工规则实验不能作为模型改写的效果证据。

保持语料、切分、top-k、权限过滤和答案判定一致。测试集在开发前冻结，改写规则只用开发集调整。报告总体和各桶的命中数/题数，同时报告无答案误答、调用数和真实测得的耗时。

**消融**：去掉改写；只做同义词扩展；增加相同预算的检索次数。若直接增加检索次数也达到同样收益，复杂改写的独立价值尚未得到证明。

## 实验 B：反思是否修复错误

**假设**：包含具体环境反馈的修正比“再检查一遍”的泛泛提示更有效。

选择失败可客观判定的受控任务，如只读工具选择或代码单元测试。比较直接重试、泛泛反思、结构化错误反馈三组；三组使用相同最大模型调用数和可用工具，记录首次成功与预算内最终成功。

这里研究的是上下文反馈机制。除非真的执行训练和参数更新，否则不要把实验写成“强化学习训练”。工具返回测试结果时，也不能把测试集标准答案直接作为修复提示，再称为独立泛化评估。

预先定义停止条件，保存失败样例，限制反思记忆长度。成功后继续生成可能把正确答案改坏，应计入实验设计。

## 实验 C：多 Agent 是否优于等预算单 Agent

选择可拆分的信息任务，把最终答案拆成可核验的事实单元。单 Agent 与多 Agent 使用同一资料库、同一访问权限和相近总 token/调用预算。并行耗时和总资源消耗分别统计。

分别测试任务可以独立拆分、子任务共享强依赖两类输入。再移除某个角色，观察收益来自更多采样、不同工具权限，还是角色分工本身。多个角色使用同一模型不意味着错误独立。

不要用多 Agent 的多次尝试，对比单 Agent 的一次尝试，然后把差异全部归因于协作。

## 怎样报告统计不确定性

先报告逐题配对结果：两个方案都对、都错、只有 A 对、只有 B 对。这比两个孤立平均分更容易揭示改动影响。样本少时直接展示分子/分母，不用小数位制造精确感。

同一个用户、同一篇文档改写出的多道题可能相关。估计不确定性时应考虑按用户或文档分组重采样；不能把重复生成的近重复题当成独立样本。随机系统应保存多次运行，给出波动与预算。

## 一份合格的复现报告

说明复现了原论文哪一个主张，哪些条件不同；公开许可允许的数据或合成替代集；记录代码版本、依赖、模型标识、提示、预算和评估器；展示一个负结果及其解释。受限于算力做小规模复现没有问题，前提是结论范围也随之缩小。

**练习**：候选方案正确 18/20，基线正确 16/20，可以宣称显著提升吗？

**参考**：只能先描述该样本上的观察差异。需要查看配对结果、采样方式、重复运行及不确定性，并确认是否同时改变预算。两道题的差别不足以自动支持统计显著性或实际业务收益。
